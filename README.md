# Augmented-Reality-Montagearbeitsplatz
Entwicklung und Evaluierung eines nutzerzentrierten Augmented-Reality-Arbeitsplatz. Die Anwendung soll Personen schrittweise durch den Arbeitsablauf führen, relevante Bauteile und Arbeitsschritte auf dem Tisch im Arbeitsbereich und daneben darstellen und verständliche Rückmeldungen zu Eingaben, Fortschritt und Fehlern geben.
